COMMAND USED
----------------------------------------
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion' |
Select-Object DisplayVersion, CurrentBuild, UBR |
Format-List

OBSERVATIONS
----------------------------------------
The Windows version and build changed between the
initial assessment and post-remediation verification.

This confirms a system version change but does not,
by itself, establish which installation mechanism
completed the upgrade.

No device identifiers or personal information included.
