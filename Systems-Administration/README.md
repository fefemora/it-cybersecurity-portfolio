Systems administration connects everyday support with the infrastructure behind it: accounts, permissions, services, and dependable Windows environments. My focus is on keeping that infrastructure manageable and secure.

## Areas of work

| Area | Focus |
|---|---|
| **Windows Server** | Roles, services, monitoring and routine administration |
| **Active Directory** | Domains, organizational units, users and groups |
| **Identity & access** | Least privilege, group-based access and lifecycle management |
| **Operations** | Troubleshooting, updates and recovery |
| **Hybrid identity** | On-premises Active Directory and Microsoft Entra ID concepts |
